# Duck Sim Lab

本地鸭子三维工作台：实机实时随动、项目真实 STL/MJCF 运动链、MuJoCo + ONNX + BAM 物理仿真、实机记录回放与 14 关节姿态编辑。

连接实机实时随动（正常 SSH 密码提示，不在项目里保存密码）：

```sh
bash tools/duck_sim/connect_live.sh root@192.168.1.11
```

打开 <http://127.0.0.1:8788>，在默认的“实机随动”页点击“连接实机反馈”。看到 `15/15`、`实时同步` 和 `扭矩关闭` 后，托稳实机轻动关节，页面模型即跟随编码器更新。2026-10-10 已由用户现场确认膝关节同步变化。

单独运行本地仿真与回放：

```sh
bash tools/duck_sim/run.sh
```

只监听本机；实时接入仅提供状态读取，不提供运控或固件更新接口。可用 `--port 8789` 指定其他端口。不要同时启动两个占用 8788 的服务。

## 操作

- **关节滑块真机随动**：在 X5 `/sim/#joints` 的「关节调试」里连接实机，确认托稳与活动间隙，再点「启用真机随动」。全部 15 个舵机使能并保持当前目标，滑块只改变所选关节；切换关节会冻结上一关节尚未完成的目标。启动以 ARM 后的新鲜编码器位置为基准，不移动到模型 HOME。首版每轮每关节限制为起点 ±10° 与保存范围的交集，转动速度可在关节滑块上方设为 1–50°/秒，默认 5°/秒；修改速度沿用当前目标角度，不自动启用。实心模型是编码器实测，紫色虚影是请求目标，两者不能当作承重证据。保存校准和固件不改变。停止、离开模式或页面隐藏会请求全部卸力；原生控制层额外执行 1000 ms 页面心跳期限，过期不得续期恢复，仍保留反馈、倾角和下位机保护。跟随误差达到 5° 时停止；刷新不能自动重连或使能。当前异步 UART owner 候选版本拒绝开启此功能，须另行验证。独立本机仿真服务没有运控接口，按钮自动禁用。

2026-10-12 已在 X5 8767 安装关节随动入口与原生接口，安装包完整性、页面资源与未启用状态下的拒绝行为已验证。校准修订 25 及原文件摘要保持不变；此次没有打开 UART 或发送电机指令，不能据此宣称实机随动已通过。实机浏览器工具读取超时，线上交互仍待现场核对。部署回执、备份位置与核验记录见 `output/duck_sim/joint-follow-20261012/deployment/`。

这项功能复用原生工作台 `/api/motion` 的登录、CSRF、页面代次和控制所有权；不在仿真服务里另开串口。原工作台已有动作时必须先停止；正在校准或维护时须先结束原会话。它只提供受支撑的关节调试，不执行物理仿真轨迹或行走。

- **三维校准（X5 工作台 `/sim/#calibration`）**：点击图中 ID 标签或列表选关节，亮色关节轴标明实际部位；紫色动画示范正方向，零姿态参考显示模型各关节零位。先连接只读校准、确认扭矩关闭并托稳机身，再手动摆动。只读范围记录由用户点击开始和结束，记录全部 15 个编码器，显示实际变化的关节，最长 120 秒并可导出 JSON。观察极值不会自动变成安全范围。
- **正式关节标定**：三维页复用原生 `/api/joint-calibration` 与 `/api/joint-zero`，按稳定采样、预览、显式保存的顺序操作；保存仍由原服务关闭读取、校验并原子更新。零点保存会清除所选关节旧方向和范围，其他关节与 IMU 保留。未保存步骤在刷新后恢复，换关节前须保存或取消。此入口覆盖模型中的 14 个关节；下颌 ID34 与 IMU 标定仍在原工作台。独立 localhost 仿真服务不提供正式校准 API。
- **实机随动**：默认页面。用 X5 保存的当前零点、方向和 IMU 标定映射实测反馈，约 30 Hz。仅同步关节与机身倾斜；世界位置、绝对偏航、足底接触没有测量数据，机身被放在固定观察高度。
- **物理仿真**：默认生成 0.20 m/s、6 秒的结果，点击底部播放按钮。更改速度和时长后点“运行物理仿真”，每段均重置模型状态。原地、慢走、前进是输入预设，不保证输出某种动作。
- **实机回放**：选择现有记录，“跳到前进指令”定位开始时间。可用 0.25× 慢放、拖动时间轴或打开目标虚影；图表与关节差值同步更新。
- **关节调试**：拖动各关节滑块，或点击三维模型选中关节。范围来自 MJCF，不会修改实机校准。此模式仅做运动学变换，不求解接触和承重。
- 拖动旋转、滚轮缩放、右键平移；视角按钮切换正面、侧面和俯视。空格播放/暂停。

## 数据含义

实时接入通过 SSH 在 X5 运行内存中的 `live_reader.py`，独占当前 CH340 串口。发送端强制限制为带 CRC 的空载荷 STATE（类型 2）；不发送 HELLO、STOP、CONFIG、ARM 或 TARGET，也不修改固件、校准或原运控服务。原始 UART 配置沿用现有工作台的方式，只观察 DTR/RTS，不主动切换控制线。若串口已有其他程序占用则拒绝接管；先在原运控页面主动断开连接。

“接收距今”表示本机最后收到反馈后的时间，不是完整端到端延迟；“串口往返”仅计 X5 与 ESP32 之间的请求/回复。若采样停止、反馈缺失或连接中断，页面保留最后姿态并标记过期，不将旧数据当作实时值。没有新浏览器查询超过 6 秒后，后台释放只读串口会话；页面切换离开实机随动或点击断开也会释放。关闭页面不会向 MCU 发 STOP。

2026-10-10 右髋 ID21 已通过无扭矩实测复核并正式保存：向内收腿时，反馈对应的编码器刻度从 2541 降到 2472；模型中右髋向内为正，因此保存方向从 +1 改为 −1。校准修订从 23 升至 24，摘要为 `1bdb21e8e3ac0f5efd02b64ac444944fb4879fa34111b00e6336afc8d6fbe98c`；零点 2209、安全范围 1971–2561、其他关节及 IMU 均保留。用户明确授权后，复用安装包中的原子校准存储模块保存，并重新载入核对。

先前页面曾对 ID21 作临时反转，用户确认了该显示方向；正式标定修正后已删除这层补偿。实时模型、数值与曲线现在直接使用同一份已保存校准。历史回放保留历史原始角度。现场验收与采样覆盖双髋侧摆，不代表所有关节或实机行走已通过验证。备份、起终点和保存回执在 `output/duck_sim/right-hip-direction-check/`。

物理模式使用 200 Hz MuJoCo 步进、50 Hz ONNX 推理、0.5 秒指令渐入；质量为参考 CAD 总质量，BAM 参数来自 `1910_m6.json`，KP 5、7.7 V。当前模型没有实机通信延迟、电源压降及个体关节辨识。模型失稳时保留失稳姿态，仿真结果不等于实机验证。参考模型在 0.12 m/s 下可能几乎原地调整，0.20 m/s 下可在模拟环境前进。

实机回放保留实际编码器角度、IMU 重力方向和尝试发送的目标。没有世界位置、偏航或足底接触测量，因此将机身固定在显示原点和参考高度；前向位移/足底接触显示未知。目标虚影表示当帧尝试发送的目标，不能推断它已被 MCU 接收执行。回放按真实时间戳取样并保持上一帧，不补造采样。页面中的 8° 停止原因来自历史记录，不表示现行保护配置。

模型包含 14 个策略关节、15 个可视网格；没有 ID34 下颌执行器。渲染颜色用于区分零件，不代表实物材质。

`output/` 是本机被忽略的输入目录；迁移到另一台电脑时需要一并准备上述模型、参考源码和记录。启动脚本优先使用本目录 `.venv`，其次尝试本机 Python 3.12 和已有模型测试包。独立安装：

```sh
python3.12 -m venv tools/duck_sim/.venv
tools/duck_sim/.venv/bin/python -m pip install -r tools/duck_sim/requirements.txt
bash tools/duck_sim/run.sh
```

可设 `DUCK_SIM_PYTHON=/path/to/python` 指定解释器。启动不自动安装依赖。

测试核对站立/前进的真实求解、双足交替接触、重置确定性、历史数据映射、IMU 方向和非法参数。将 20 组姿态下 Three.js 的全部连杆变换与 MuJoCo 比较，检查关节轴、父子层级和弧度/角度转换；需 Node.js 执行此项测试。

方向专项测试重放本次右髋 2541→2472 的内收采样：新标定使模型角度增加，三维右脚向机身中心（+Y）移动，左腿保持不变。反馈测试核对修订 24 的符号换算、其他关节保留和页面不再需要额外反转。几何测试不能代替实机装配方向的现场核对。

实时专项测试覆盖 STATE 命令白名单、CRC/序号解码、校准角度映射、旧帧/积压/缺失数据的过期处理。X5 固件本身仍有自主采样与保护逻辑，反馈程序不修改这些机制。

实机随动连接期间会核对保存校准文件的版本标识。文件被替换或更新时，在发布下一帧前结束旧反馈并提示重新连接，避免新反馈继续按旧方向解码；不自动重连，也不发送动作。

### 关节编号标注

三维校准、实机随动和关节调试按当前部位显示完整编号：左腿 ID10–14、右腿 ID20–24、头颈 ID30–33。编号引线固定在 MJCF 输出轴位置；亮线表示轴向，被外壳遮挡的轴仍可选。ID34 下颌未包含在模型中。

CAD 连杆网格可能包含相邻舵机的外壳，不能把整块网格当作舵机身份。因此这些模式使用 ID 标签和关节列表选取，不再通过点击整块网格选取。编号参照仓库 `Assembly_Guide.pdf` 第 1 页及运行时策略顺序；这不等于已逐只确认用户实物的总线 ID。本次只改变显示和选择方式，不修改编码器映射、零点、方向、范围或运控。
