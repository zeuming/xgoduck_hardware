校准怎么做

配置保存在 X5，重启后保留

先支撑机身、让双脚悬空，点击上方“停止并释放”。下方采集只读取编码器；请用手缓慢摆放关节，任何机械阻力都不要强推。

  1. 逐个把关节摆到训练模型的 q = 0 机械姿态，点击“记零点”。模型默认站姿有弯曲角度，不能直接当零姿态。
  2. 将关节缓慢摆到允许的安全活动端点，分别记录编码器较小的一端为下限、较大的一端为上限。保留机械余量，勿顶死；跨过 4095 → 0 的范围需先检查装配。
  3. 对照模型正方向手动摆动：编码器增加对应模型角度增加，选择 +1；对应角度减少，选择 −1。确认后勾选该行“方向已核实”。
  4. 嘴部 ID 34 以闭合位置作零点，张开方向为正，也需记录安全范围并核实方向。
  5. 核实 IMU 轴向，保持机身水平静止后采样校准；全部通过后先测试默认站姿，确认姿态与关节方向，再用小速度启动行走。
需要可核实的机械零姿态参考。 先对照下方训练模型零姿态图，再核对本机安装方向。打开模型零姿态参考图；也可查看项目装配图辅助辨认关节。请勿把出厂 2047 或另一只鸭子的零点直接填入本机。
